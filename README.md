An interactive Netflix Analytics Dashboard built using **Python**, **Streamlit**, and **Pandas**. The application enables users to explore Netflix Movies and TV Shows through interactive filters, visualizations, smart recommendations, and AI-inspired insights.

---

## 📌 Project Overview

The Netflix InsightGen AI Dashboard is a mini data analytics project that provides users with an interactive interface to analyze Netflix content. The dashboard allows users to filter the dataset, visualize trends, generate insights, and explore recommendations based on different categories.

This project demonstrates fundamental skills in data analysis, dashboard development, and Python programming using the Streamlit framework.

---

## ✨ Features

- 🎬 Interactive Netflix Dashboard
- 🔍 Filter content by Type (Movie / TV Show)
- 📅 Filter content by Release Year
- 📊 Display Netflix Dataset
- 📈 Key Performance Indicators (KPIs)
  - Total Titles
  - Total Movies
  - Total TV Shows
- 📉 Content Distribution Charts
- 🎯 Smart Recommendation System
- 🤖 AI-inspired Data Insights
- 💬 Basic Question Answering Interface

## 🚀 Installation

### Clone the Repository

```bash
git clone https://github.com/amruthabandaru/netflix-ai-dashboard-.git
```

### Navigate to the Project Folder

```bash
cd netflix-ai-dashboard-
```

### Install Dependencies

```bash
pip install -r requirements.txt
```

### Run the Application

```bash
streamlit run app.py
```
